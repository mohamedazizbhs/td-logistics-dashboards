Same network, three different decisions

One French logistics network with 3 existing warehouses and 20 real French cities. Distances are computed from real coordinates. Three dashboards are designed for three different decision-makers, each with different KPIs and charts.

Sustainability / CSR manager

CO2 Dashboard

Which routes should we prioritize to cut network CO2? Ranked bar chart and a geographic visualization to identify where emissions concentrate.

Logistics / Operations manager

Cost Dashboard

Where does cost concentrate — transport or storage? A stacked bar chart and a detailed table to identify the main cost drivers.

Strategic / Network planning manager

Network Dashboard

Should we open a warehouse in Bordeaux or Marseille, or close Lille? Scenario comparison and geographic visualizations to evaluate the network configuration.
